# Adaptive Python Exam (CLI)

A small command-line exam that adapts to the person taking it. It reads a bank of
questions from a CSV file, asks them one by one, moves the difficulty up or down
depending on the answers, and ends with an estimated level (1–5).

Pure Python 3, standard library only. The exam interface and the question bank
are in Russian.

## What it does

- Three question types: single choice, multiple choice, short answer.
- Difficulty "ladder": a correct answer raises the level, a wrong one lowers it,
  no answer keeps it. If a level has no questions left, the nearest level is used.
- Two ways to compute the final level: *last correct answer* (default) and
  *stable level* (`--stable`: highest level with at least two correct answers).
- Tolerant bank loader: broken lines are skipped and counted instead of crashing.
- Results are appended to a CSV file (`name;level;asked;correct`).

## Quick start

```bash
python3 src/exam.py                       # default bank, default rule
python3 src/exam.py --stable              # stable-level rule
python3 src/exam.py --bank a.csv b.csv    # questions from several files
python3 src/bank_cli.py data/python_basics.csv --matrix   # topic x level table
python3 -m unittest discover -s tests -v  # run the tests
```

## Question bank format

UTF-8, `;` separated, first line is a header:

```
id;тема;уровень;тип;вопрос;варианты;ответ
4;строки;2;короткий;Что напечатает код?\ns = "Python"\nprint(s[0] + s[-1]);;Pn
```

- `\n` inside the text is a line break; options are separated by `|`.
- Answer: one option number (`один`), several numbers like `1,3` (`несколько`),
  or accepted spellings like `strip|strip()` (`короткий`).
- `data/python_basics.csv` contains 35 original questions (4 topics, 5 levels).
  The expected output of every code question was generated by running the code.

## Project structure

```
src/
  bank.py       load_bank, find_question, question_lines, count_* helpers
  bank_cli.py   inspect a bank: --show ID, --stats, --matrix
  answers.py    check_answer -> "верно" / "неверно" / "нет ответа"
  ladder.py     next_level, pick_question
  exam.py       run_exam (testable, no direct I/O), final-level rules, CLI
scripts/        first-stage programs: one question, one answer, one verdict
tests/          33 unit tests (unittest, also runs under pytest)
data/           question bank
```

## Design notes

- **I/O at the edges.** `bank.py`, `answers.py` and `ladder.py` never print.
  `run_exam()` talks through two callbacks (`read_line`, `write`), so the whole
  conversation is unit-tested without a terminal.
- **"No answer" is not "wrong".** An empty answer or end of input is reported
  separately, and the program never exits with an error code because of it.
- **Edge cases are tested:** `"02"` is not option 2, `1,1,3` has a repeated
  number, a missing bank file produces a message instead of a traceback.
